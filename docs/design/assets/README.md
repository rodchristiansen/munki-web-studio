# Design assets

`munkistudio.png` is the 256-pixel icon representation extracted from
MunkiStudio 2026.09.28 (build 1209), supplied by the installed app's
`MunkiStudio.icns`. It is used as the requested app identity in the local design
study. The editable icon source belongs to the companion MunkiStudio project at
`resources/MunkiStudio.icon`.
