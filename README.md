# Munki Web Studio

A web workspace for Munki software repositories: browse packages, edit
pkginfo and manifests, review changes, and publish through an explicit workflow.
Inspired by MunkiStudio and the job MunkiWebAdmin has always done.

Munki Web Studio is the Munki build of
[FleetMate Web Admin](https://github.com/rodchristiansen/fleetmate-web-admin).
The source, plans, and design studies live there; this repository receives
releases. [Cimian Web Studio](https://github.com/windowsadmins/cimian-web-studio) is the sibling build for Cimian.

**Status: planning. There are no releases yet.**

- Plans: [docs/munki/](https://github.com/rodchristiansen/fleetmate-web-admin/tree/main/docs/munki)
